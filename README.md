# VoltGuard BMS — 4S Lithium-Ion EV Battery Management System & Cell Balancing Lab

> Interactive 4S1P NMC Lithium-Ion Electric Vehicle (EV) Battery Management System (BMS) simulator featuring non-linear OCV-SoC lookup modeling, Coulomb-counting State of Charge estimation, MOSFET passive shunt cell balancing, $I^2R$ cell thermodynamics, and OVP/UVP/OCP/OTP main contactor cutoff protection.
